# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

This is a research repository for designing a system that dynamically adds and removes LoRA adapters for LLMs to better solve tasks in an agentic way.

## Code Style

- **Docstrings**: Google style for all functions and classes (Args/Returns/Raises sections where applicable).
- **Comments**: Used sparingly — only on lines where a short explanation is genuinely needed. Single line, no banners or separator blocks.
- **No separators**: Never use `# ---` or similar decorative lines.
